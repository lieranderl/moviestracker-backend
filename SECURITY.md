# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/lieranderl/moviestracker-backend/security/advisories/new)
rather than in a public issue or pull request.

Include the affected component (`getmovies`, `getimdbrating`,
`downloadimdbdata`, or `infra/`), steps to reproduce, and the impact you
expect. You should receive an acknowledgement within a week.

## Supported versions

Only the latest release deployed to production is supported. Fixes are
released as a new version rather than backported.
